# Lexi26 Android v1.3

무료 오프라인 다국어 단어 암기 앱. Android Studio(Java/SQLite) 프로젝트입니다.

## v1.3
- 첫 실행 시 빈 단어장이라면 영어 40개, 프랑스어 40개의 자체 구성 입문 어휘를 자동으로 등록합니다.
- 기존 v1.2 사용자도 앱을 업데이트하면 단어장이 비어 있을 때 기본 어휘가 자동으로 채워집니다. 기존 단어가 있으면 덮어쓰지 않습니다.
- 목표 탭에서 학습 언어, 현재 수준, 목표 수준, 남은 기간, 일일 신규 단어 목표를 저장할 수 있습니다.
- 26초 자동 스키밍, 플래시카드, SM-2 계열 간격 반복, TTS, CSV 가져오기/내보내기를 유지합니다.

## 데이터 안내
기본 어휘 팩은 Lexi26 프로젝트가 직접 구성한 소규모 입문용 샘플입니다. 공식 CEFR 어휘 목록이나 DELF/TOEIC 등 시험의 공식 단어 목록이 아닙니다. 현재 수준·목표 수준 설정은 학습 계획을 기록하기 위한 기능이며, 아직 진단 테스트나 수준별 공식 어휘 필터를 제공하지 않습니다. 일일 신규 단어 수와 기간을 이용한 값은 계획량 계산이며, 실제 학습 성취를 보장하지 않습니다.
